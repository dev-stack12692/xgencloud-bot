Memory is 360,000,000 bytes. CPU is capped at 30% of one core while the container runs. Outbound internet is limited to HTTPS (port 443). Your files are never run on the host, only inside your container.

Apps to run

Pick which uploaded file starts each app (up to 5 per container; all share the one 360 MB / 30% budget). Python runtime runs .py files, Node.js runs .js/.mjs/.cjs. If you skip this and upload bot.py / main.py / app.py / index.py (Python) or index.js / bot.js / main.js / app.js (Node), that file is started automatically as one app. Crashed apps restart up to 5 times per 10 minutes.
